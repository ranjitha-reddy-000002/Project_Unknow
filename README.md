# Afterglow website prototype

A responsive, single-page website concept for a brand about meaningful surprises, future memories, unsent letters, and real-world treasure hunts.

## Run locally

1. Extract the ZIP file.
2. Open the `afterglow-website` folder.
3. Double-click `index.html` to open it in a modern browser.

No npm, framework installation, database, API key, or build step is required.

Optional: if you use VS Code, install/use the Live Server extension and choose **Open with Live Server**.

## What is included

- Responsive desktop, tablet, and mobile layouts
- Sticky navigation and mobile menu
- Hero section, experience cards, About section, how-it-works section, treasure-hunt concept, memory vault, privacy principles, CTA, and footer
- Reusable interactive interest/enrollment modal
- Form validation and demo success state
- Scroll reveal animations and back-to-top control
- Image alt text and reduced-motion support

## Important prototype limitations

- The enrollment form is frontend-only. It does **not** transmit or save submitted details.
- There is no account system, database, email delivery, payment system, live hunt, or secure memory storage.
- Images load from Unsplash URLs and Google Fonts load from Google Fonts, so those assets need an internet connection.
- “Afterglow” is a placeholder brand name. Check domain and trademark availability before using it commercially.
- Replace the demo contact email before launch.
- Before collecting real letters, photographs, floor plans, or personal information, build a secure backend, retention/deletion controls, clear consent, and a privacy policy.
- Before launching real-world hunts, use authorized, safe locations and publish clear rules and prize terms.
